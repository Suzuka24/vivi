# ImageJ LUT tables

`imagej_luts.npz` contains 89 uniquely named lookup tables combined from the [ImageJ LUT archive](https://imagej.net/ij/download/luts/luts.zip), the ImageJ 1.54 cross-platform distribution, and the [Fiji LUT directory](https://github.com/fiji/fiji/tree/main/luts), plus eight numbered favorites exposed at the start of the menu. Each table is stored as an exact 256 × 3 RGB byte array. `imagej_luts_manifest.json` records the menu names. The ImageJ 1.x [license and disclaimer](https://github.com/imagej/ImageJ/blob/master/LICENSE.txt) describes ImageJ as public domain; Fiji's repository is licensed under GPL-2.0.

The original `.lut` files use planar RGB bytes (768 bytes), an ImageJ ICOL header plus 768 bytes (800 bytes), or 256 lines of RGB text. Identical names shared by these sources have identical byte tables and are included once. The menu's `000` through `007` favorites are exposed alongside the clean names as equivalent menu aliases. ImageJ's programmatic built-ins remain separate, with Fire, Ice, Spectrum, 3-3-2 RGB, and Red/Green generated exactly as `LutLoader` does. The menu combines these tables with vivi's remaining custom color maps and sorts all display names.
