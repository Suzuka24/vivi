# 数值显示与缩放交互

## 计划

- 目标：统一界面数字为最多八字符（参照 `3.22e-12`），让 B&C 曲线随调整实时变化，修复最小化图标和工具栏对齐，并调整默认工具与缩放锚点。
- 范围：Explorer 的 Adjust、Viewer 的 B&C、统计结果和像素读数、工具栏与缩放事件。
- 步骤：加入共享数字格式函数；更新显示与交互；检查构建；优先在远程 Cursor 验证并安装，再同步本地与 GitHub。
- 验证：Node 静态检查、单元测试、扩展打包和远程实际图像交互。

## 实施记录

- 使用共享八字符格式函数代替两套数字格式代码；保留统计数据导出的原始精度。
- Adjust 操作直接刷新 B&C 曲线，缩小最小化横条时标题与按钮居中，Results/Histogram 最小化后显示恢复图标。
- 第一行工具栏对齐 Fit、1:1 等控件。新图像默认 Pan；滚轮按鼠标点缩放，按钮和键盘按图像中心缩放。
- 静态检查、八项 Node 测试及差异空白检查通过。

## 总结

- `npm run check`、`npm test`（8/8）与 `git diff --check` 通过，VSIX 打包成功。
- 远程 Cursor 安装 0.6.5 并用真实 TIFF 检查：Minimum 显示为八字符以内，输入 `0.01` 后 B&C 刻度同步为 `0.01`；最小化后曲线隐藏。滑动过程中的逐帧视觉效果由 `oninput` 代码保证，未做录屏测量。
- 本地 Cursor 也安装 0.6.5。待推送 GitHub。
