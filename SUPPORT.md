# Support

Read the [installation guide](docs/installation.en.md) and run **vivi: Check Python Backend** before filing an issue. If the extension was just installed or upgraded, run **Developer: Reload Window**.

For a reproducible bug, open a [GitHub issue](https://github.com/Suzuka24/vivi/issues) with:

- vivi version and editor/version (VS Code or Cursor);
- operating system, Remote SSH host type if relevant, Python version, and installed backend package versions;
- file format, dimensions, dtype, stack axes, and approximate file size;
- exact steps, expected result, actual result, and a screenshot for visual issues;
- relevant errors from the **vivi** Output channel.

A small synthetic file that reproduces a format bug is useful. Do not upload private images, raw server paths, tokens, or personal data. Replace identifying paths in logs. For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
